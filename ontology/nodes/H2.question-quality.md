## L0 这是什么

**问题质量**指：一个问题是否说清了已知、未知、成功标准，以及回答是否可被检验。  
糊问题不是「不够聪明」，而是意图与边界尚未外化——对方（人或 AI）只能猜你要什么。

消歧：这里谈的不是应试「审题技巧」，而是学习、协作与教人时的**提问能力**本身。

## L2 模型

一个可迁移的最小结构：

1. **已知**：我已经确认了什么？  
2. **未知**：我真正缺的是哪一块？  
3. **成功标准**：怎样的回答算「够用」？  
4. **约束**：时间、对象、不可接受的捷径是什么？

好问题缩小搜索空间；坏问题把责任推给答者。AI 越强，糊问题越容易换来流畅但无用的长文——这不是模型的胜利，是提问的失败。

与代际的连接：教孩子「怎么想」往往从**不急着答、先帮他把问题问清楚**开始。

## L1 练习

1. 写下本周一个真实困扰（工作、学习或亲子均可）。  
2. 用四栏改写：已知 / 未知 / 成功标准 / 约束。  
3. 拆成 3 个更小的问题；只选 1 个今天就能推进。  
4. （可选）把第 3 步问给 AI，但你必须先写验收标准，再对照输出是否达标。
